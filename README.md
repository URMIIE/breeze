# breeze

실리태번을 쓰면서 아쉬웠던 자잘한 것들을 한데 모은 확장이에요. 기능마다 따로 켜고 끌 수 있고, 처음에는 전부 꺼져 있어요. 꺼 둔 기능은 코드를 불러오지 않아요.

실리태번 1.19 에서 만들고 시험했어요.

## 설치

실리태번 ‘확장 설치’에 이 저장소 주소를 넣으면 돼요. 설치한 뒤 확장 설정 창의 ‘breeze’에서 쓰고 싶은 기능을 켜세요. 묶음마다 탭으로 나뉘어 있고, 자세한 설정이 있는 기능은 켠 뒤 ⚙ 를 누르면 펼쳐져요.

## 기능

### 채팅
- **스와이프 복사**: 지금 메시지를 새 스와이프로 복사해요. 메시지의 » 버튼을 누르거나 채팅창에 `/dup` 을 치면 돼요.
- **읽던 자리 기억**: 읽던 자리는 브라우저에만 적어 둬요.
- **메시지별 정규식 유지**: 메시지마다 만들 때 켜져 있던 정규식으로 그려요. 프리셋을 바꾸거나 정규식을 켜고 꺼도 지난 메시지는 그때 모양 그대로예요. AI 에게 보낼 때는 지금 정규식을 따라요. 짝 서버 플러그인이 있어야 해요.
- **답에 들어간 월드인포 보기**: 답마다 이름 옆에 '월드인포 N'이 붙어요. 누르면 그 답에 들어간 항목이 옆에 작은 목록으로 뜨고, 항목을 누르면 월드인포 창에서 바로 열려요.
- **상태창 흰 바탕 제거**: 바탕을 투명하게 만든 상태창이 어두운 테마에서 흰 상자로 뜨는 걸 고쳐요. 바탕색을 직접 칠해 둔 상태창은 그대로예요.

### 메시지 버튼
- **메시지 버튼 관리**: 자주 쓰는 버튼은 늘 보이게, 안 쓰는 버튼은 숨겨요. 줄을 끌어서 버튼 순서도 바꿀 수 있어요.
- **드래그 메뉴 합치기**: 글을 드래그하면 여러 확장이 따로 띄우는 버튼을 ⋯ 하나로 모아요.

### 목록 · 설정 창
- **미리보기를 화면과 같게**: 홈 · 채팅 파일 목록의 미리보기에 채팅 화면에서 보이는 그대로 띄워요. 생각 글 · 화면에서 숨는 태그는 빼고 보여 줘요.
- **채팅 파일 관리 창 보기 쉽게**: 채팅 기록 창에서 채팅을 열지 않고 처음 · 마지막 대화를 펼쳐 봐요. 정렬하거나 여러 채팅을 골라 한 번에 내보내고 지울 수 있어요.
- **월드인포 창 정리**: 월드인포 창 모양을 바꿔요. 월드인포가 목록으로 펼쳐져 지금 채팅에 쓰는 것 · 캐릭터별 등으로 알아서 묶이고(폴더도 만들 수 있어요), 항목은 한 줄로 접혀 한눈에 보여요.
- **확장 관리 창 검색칸**: ‘확장 관리’ 창 맨 위에 확장 찾는 칸을 붙여요. 초성으로도 찾을 수 있어요.
- **알림 숨기기**: 알림 오른쪽 아래 눈 모양을 누르면 그 알림은 다음부터 안 떠요. 숨긴 알림은 설정에서 다시 보이게 할 수 있고, 숨길 알림이 더 없으면 버튼을 끌 수 있어요.
- **월드인포 토큰 수 정확하게**: 월드인포 항목 토큰 수를 모델에 실제로 보내는 글 기준으로 세요. 메모용 `{{// }}` 주석은 모델에 안 가서 빼고 세요.

### 꾸미기
- **테마 스크립트 자동 켜기**: 테마 이름 · 테마가 정한 CSS 변수 · 테마 CSS 안 글자 가운데 하나를 조건으로 CSS · JS 를 넣어 두면, 그 테마일 때만 켜고 벗어나면 끄고 치워요. 규칙은 내보내고 들여올 수 있어요. **들여온 JS 는 실리태번 안에서 실행되니 믿을 수 있는 곳에서 받은 것만 들여오세요.**
- **로딩 화면**: 준비된 화면(고양이 · 낮, 고양이 · 밤)을 고르거나 배경색 · 그림 · 로고 · CSS 로 꾸며요. 테마에 로딩 화면이 있어도 내 화면을 쓰게 할 수 있어요. 서버 플러그인이 없으면 설정 창에 나오는 한 줄을 `css/user.css` 에 직접 넣어야 보여요.
- **추론 칸 꾸미기**

### 가볍게
- **보이는 메시지만 그리기**
- **최근 채팅 바로 표시**: 홈에 지난번 최근 채팅을 먼저 띄워요. 목록이 달라졌으면 그때 바꿔 그려요.
- **최근 채팅 바로 열기**: 홈 화면 최근 채팅을 열 때 그 캐릭터의 마지막 채팅을 거치지 않고 그 채팅을 바로 열어요.
- **보이는 채팅 파일만 그리기**: 화면 밖 줄은 그리기를 건너뛰고, 창을 닫으면 목록을 비워요.
- **보이는 월드인포 항목만 그리기**
- **보이는 프로필 사진만 불러오기**
- **완료 알림음**: 메시지 생성이나 다른 확장의 일(번역 등)이 끝나면 소리로 알려요.

## 다른 확장 · 테마와 같이 쓸 때

같은 일을 이미 다른 확장이나 테마가 하고 있으면 그 기능은 알아서 쉬어요(예: 누가 이미 버튼을 메시지에 꺼내 놓았을 때, 채팅을 열 때 다른 쪽이 먼저 읽던 자리로 옮길 때, 메시지에 이미 화면 밖 건너뛰기가 걸려 있을 때). 확장 이름으로 찾지 않고 실제로 하고 있는지를 봐요.

## 서버 플러그인 (원하는 사람만)

`server-plugin/breeze-server` 폴더를 실리태번의 `plugins` 폴더에 넣고, `config.yaml` 의 `enableServerPlugins` 를 `true` 로 바꾼 뒤 서버를 다시 켜면 돼요.

- 프리셋 · 테마를 쓸 때만 불러와 빨리 켜기
- 새로고침 빠르게 (바뀌지 않은 설정 폴더는 다시 안 읽기)
- 채팅 목록 빨리 띄우기 (바뀌지 않은 채팅은 다시 안 읽기) + 미리보기 · 채팅 펼쳐 보기용 정보
- 같은 컴퓨터에서는 압축 없이 보내기
- 메시지별 정규식 유지용 연결 지점
- 로딩 화면 파일 읽기
- 브라우저 탭 아이콘 바꾸기: 플러그인 폴더에 `icons` 폴더를 만들고 `favicon.ico`, `apple-icon-57x57.png` 처럼 실리태번과 같은 이름의 파일을 넣어요.

**실리태번 파일을 고치지 않아요.** 서버가 켜져 있는 동안 메모리에서만 끼워 넣기 때문에 실리태번 업데이트를 막지 않고, 플러그인 폴더를 빼고 서버를 다시 켜면 그대로 원래대로예요. 실리태번이 업데이트되어 끼울 자리가 달라지면 그 기능만 쉬고 서버 창에 알려요. 상태는 breeze 설정 창 맨 아래에서 볼 수 있어요.

플러그인 새 판은 breeze 설정 창 맨 아래 '서버'에서 바로 받을 수 있고, 실리태번 서버를 켤 때 자동으로 받게 해 둘 수도 있어요.

기능을 골라 끄려면 플러그인 폴더에 `config.json` 을 만들어요.

```json
{ "features": { "no_local_compression": false } }
```

이름: `lazy_load` · `folder_cache` · `chat_cache` · `no_local_compression` · `regex_hook` · `loading_screen` · `tab_icon`
